# منصة المساعد التعليمي - واجهة الويب (Teacher Assistant LMS Frontend)

تطبيق الواجهة الأمامية لنظام إدارة التعلّم متعدد المستأجرين (Multi-Tenant SaaS)، مبني على غرار منصة Shopify لتمكين كل معلّم من امتلاك منصة تعليمية مستقلة ذات هوية بصرية مخصصة واسم نطاق خاص لطلابه.

---

## 🏛️ القواعد المعمارية الأساسية (Architecture Rules)

1. **موقع المنصة الرئيسي (Platform Site: `localhost:5173` بدون تينانت):**
   - هو **لوحة تحكم المعلم (Teacher Control Panel)** المركزية: تسجيل دخول المدرس، لوحة المتابعة، إعدادات الهوية والمظهر، المواد الدراسية، الدروس، المجموعات، والطلاب.
   - يتحكم المعلم في منصته الخاصة عن طريق إرسال ترويسة `X-Tenant: <subdomain>` تلقائياً عبر الـ `apiClient` بناءً على المنصة التي يمتلكها المعلم المسجل.
   - تسجيل دخول المعلم يتواجد **فقط** على موقع المنصة الرئيسي (`/teacher/login`).

2. **موقع المعلم الخاص (Tenant Site: `demo.localhost:5173` أو `/t/demo`):**
   - مخصص **للطلاب فقط (Students Only - View Only)**.
   - **لا يعرض نهائياً أي أدوات تعديل أو إدارة**، حتى لو قام المعلم مالك المنصة بزيارته وهو مسجل الدخول، بل يظهر له إشعار ورابط لطيف يوجهه للوحة التحكم بالمنصة الرئيسية.
   - تسجيل دخول الطالب وإنشاء حساب الطالب يتواجدان **فقط** على موقع المعلم (`/login` و `/register`).
   - إنشاء حساب الطالب **يتطلب إجبارياً كود الجروب ("كود الجروب")** المكوّن من 8 خانات المقدم من المعلم.

3. **الفصل الصارم للأشرطة العلوية (Navbar Isolation):**
   - مسارات المنصة ولوحة التحكم تعرض **فقط** `PlatformLayout` (شريط المنصة).
   - مسارات منصات المعلمين والطلاب تعرض **فقط** `TenantLayout` (شريط المنصة الخاصة).
   - في كلا الوضعين (Subdomain Mode و Path Mode) لا يمكن لصفحة أن تعرض الشريطين معاً؛ حيث تم ضبط هيكل المسارات كأشقاء (Siblings) مستقلين.

## 🛠️ التقنيات والمكتبات المعتمدة (Tech Stack & Approved Libraries)

- **Vite 6** + **React 18** + **TypeScript** (Strict mode)
- **Tailwind CSS v3** (مع فئات منطقية RTL مثل `ms-`, `me-`, `ps-`, `pe-` ورموز التصميم في `tokens.css`)
- **React Router v6** (مع تفعيل `v7_startTransition` و `v7_relativeSplatPath`)
- **TanStack Query (React Query v5)** (إدارة وتخزين مؤقت للبيانات وإبطال الكاش)
- **Axios** (مع Interceptors لترويسة `X-Tenant` والتوكن وحالات 401 والتوجيه الذكي ومعالجة 429 والتبريد التلقائي)
- **React Hook Form** + **Zod** (تحقق فوري من الحقول وقواعد كلمة المرور وربط أخطاء الخادم 400 أسفل الحقول)
- **المكتبات المساعدة المعتمدة فقط**: `clsx`, `tailwind-merge`, `sonner`, `@radix-ui/react-dialog`, `@radix-ui/react-dropdown-menu`, `@dnd-kit/core`, `@dnd-kit/sortable`, `date-fns`, `lucide-react`.

## 👥 بيانات الحسابات التجريبية (Demo Accounts & Seed Data)

*ملاحظة أمنية: يتم تهيئة هذه البيانات فقط في بيئة التطوير (Development) ولا يتم تضمينها نهائياً في حزم الإنتاج.*

### 1. حسابات الدخول (كلمة المرور الموحدة: `Demo@12345`):
| الحساب | الدور | البريد الإلكتروني | المجموعة المسجل بها | رابط تسجيل الدخول |
| :--- | :--- | :--- | :--- | :--- |
| **المعلم التجريبي** | Instructor | `teacher@demo.local` | مالك منصة `demo` | `http://localhost:5173/teacher/login` |
| **طالب 1 (أحمد علي)** | Student | `student1@demo.local` | مجموعة السبت (`SAT5CHEM`) | `http://demo.localhost:5173/login` أو `/t/demo/login` |
| **طالب 2 (مريم حسن)** | Student | `student2@demo.local` | مجموعة الإثنين (`MND7CHEM`) | `http://demo.localhost:5173/login` أو `/t/demo/login` |
| **طالب 3 (عمر خالد)** | Student | `student3@demo.local` | مجموعة السبت (`SAT5CHEM`) | `http://demo.localhost:5173/login` أو `/t/demo/login` |
| **مدير المنصة العام** | Admin | `admin@platform.local` | - (كلمة المرور: `Admin@12345`) | `http://localhost:5173/teacher/login` |

### 2. محتوى المادة التجريبية في منصة "demo":
- **المادة الأساسية المنشورة**: «كيمياء - تالتة ثانوي»
  - **الدرس 1 (فيديو YouTube)**: «مقدمة الكيمياء العضوية وتصنيف الهيدروكربونات»
  - **الدرس 2 (ملف Google Drive)**: «ملخص قوانين الكيمياء الكهربية وخلايا فاراداي»
  - **الدرس 3 (ملف PDF مباشر)**: «بنك أسئلة وتدريبات الاتزان الكيميائي (PDF)»
  - **الدرس 4 (مقال تعليمي)**: «دليل إتقان مسائل الكيمياء التحليلية والمعايرة»
- **المادة المسودة (Draft Subject)**: «مراجعة ليلة الامتحان في الفيزياء (مسودة)» (غير منشورة للطلاب، تظهر للمعلم فقط).
- **المجموعات وأكواد الانضمام**:
  - مجموعة السبت 5 مساءً: الكود `SAT5CHEM`
  - مجموعة الإثنين 7 مساءً: الكود `MND7CHEM`

في كل من صفحة دخول المعلم وصفحة دخول الطلاب، يظهر صندوق قابل للطي بعنوان **«حسابات تجريبية (بيئة التطوير)»**:

## 🚀 دليل البدء السريع لزملاء الفريق (Getting Started for Teammates)

### المتطلبات المسبقة (Prerequisites)
- **.NET 10.0 SDK** (أو أحدث): `dotnet --version`
- **Node.js** (v18+ أو v20+) و **npm**: `node -v` و `npm -v`
- **SQL Server** أو **LocalDB**: `(localdb)\mssqllocaldb` أو SQL Server محلي
- **Git**

### خطوات التثبيت والتشغيل السريع:

#### 1. استنساخ المستودع وضبط ملف البيئة
```bash
git clone <repository-url>
cd "TeacherAssistantLms"

# الانتقال للفرونت إند وإعداد متغيرات البيئة
cd src
cp .env.example .env
npm install
```

#### 2. تشغيل الباك إند (Backend API)
```bash
dotnet run --project TeacherAssistant.API --launch-profile http
```
*(يعمل على المنفذ `http://localhost:5014`، والتوثيق التفاعلي على `http://localhost:5014/scalar/v1`)*
*(يتم تطبيق الـ Migrations وتوليد حسابات وبيانات الديمو تلقائياً عند أول إقلاع)*

#### 3. تشغيل الواجهة الأمامية (Frontend Dev Server)
```bash
npm run dev
```
*(تعمل على المنفذ `http://localhost:5173`)*

#### 4. تشغيل الاختبارات المؤتمتة
```bash
dotnet test "..\tests\TeacherAssistant.IntegrationTests"
```
*(تم التحقق من نجاح جميع الاختبارات الـ 52 بنسبة 100%)*
